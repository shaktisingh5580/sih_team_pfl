# ORCA — Marine EcOsystem Reasoning with Collaborative Agents
### Smart India Hackathon 2026 · Problem Statement 26176
**Ministry / Organization:** ISRO / Department of Space

ORCA is an intelligent conversational platform for marine decision support. It is not just a chatbot with a map; it is a **Marine Decision Workspace** where user queries trigger autonomous multi-agent investigations, grounding every recommendation with verified scientific data and evidence chains.
